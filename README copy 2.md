# PTI SAU

Программа для генерации аналоговых сигналов, воспроизведения сценариев
и обмена данными с PLC Modicon Premium по протоколу Modbus TCP.

Проект предназначен для формирования сигналов на нескольких аналоговых
каналах, воспроизведения последовательности заданных режимов и передачи
текущих значений каналов в PLC.

---

## Возможности

- генерация аналоговых сигналов;
- до 20 аналоговых каналов;
- настройка типа сигнала;
- настройка частоты, амплитуды и смещения;
- ограничение значения сигнала диапазоном канала;
- включение и отключение отдельных каналов;
- воспроизведение сценариев;
- пауза и продолжение сценария;
- зацикливание сценария;
- сохранение и загрузка сценариев в формате JSON;
- настройка времени выполнения отдельных шагов сценария;
- подготовка параметров для плавного изменения сигнала (`ramp`);
- обмен данными с PLC Modicon Premium по Modbus TCP;
- передача значений каналов в формате IEEE-754 REAL;
- асинхронная запись данных в PLC;
- отображение состояния подключения и ошибок;
- режим отладки обмена с PLC.
