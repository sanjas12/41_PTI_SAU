# PTI_SAU

Настольное приложение для генерации сигналов и прямого управления восемью
аналоговыми выходами ОВЕН МУ210-501 по Modbus TCP.


## Установка (из репозитория)

### 1. Требования

| Параметр | Значение |
|---|---|
| Python | 3.8.10 |
| ОС | Windows 7 и выше |
| [uv](https://github.com/astral-sh/uv) | 0.11.7 |

### 2. Настройка окружения

#### 2.1 Пересоздание виртуального окружения

Скрипт удаляет существующую `.venv`, создаёт её заново, устанавливает
зависимости и Git hooks:

```bash
bash scripts/recreate_env.sh
```

#### 2.2 Установка зависимостей (если скрипт из пункта 2.1 не сработал)

Рекомендуется — через [uv](https://github.com/astral-sh/uv):

```bash
uv sync
```

Без uv:

```bash
pip install -r requirements.txt
```

> `requirements.txt` генерируется из `pyproject.toml` — не редактировать вручную.

### 3. Запуск

#### 3.1 C uv

```bash
uv run python src/main.py
```

#### 3.2 Без uv

```bash
source .venv/Scripts/activate
python src/main.py
```

### 4. Сборка EXE

Сборка с использованием уже подготовленного окружения:

```bash
bash scripts/build.sh
```

Полная последовательность с предварительным удалением и пересозданием `.venv`:

```bash
bash scripts/build_all.sh
```

> `build_all.sh` удаляет текущее виртуальное окружение через
> `recreate_env.sh`. Для обычной повторной сборки используйте `build.sh`.

## Подключение МУ210-501

Приложение передаёт первые восемь аналоговых каналов напрямую в оперативные
регистры `3000–3007` модуля одной командой Modbus TCP. Значения масштабируются
в диапазон `0–1000`, соответствующий `0,0–100,0 %` диапазона выхода.

Перед подключением реального оборудования задайте в ОВЕН Конфигураторе режим
каждого выхода (напряжение или ток) и безопасное состояние. Приложение не
изменяет эти параметры автоматически. Заводской IP модуля — `192.168.1.99`,
порт Modbus TCP — `502`; фактический адрес может отличаться после настройки.
