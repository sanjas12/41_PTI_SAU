# PTI_SAU

Настольное приложение для генерации сигналов и обмена по Modbus TCP с PLC
Modicon Premium, симулятором или напрямую с восемью аналоговыми выходами ОВЕН
МУ210-501.


## Установка (из репозитория)

### 1. Требования

| Параметр | Значение |
|---|---|
| Python | 3.8.10 |
| ОС | Windows 7 и выше |
| [uv](https://github.com/astral-sh/uv) | 0.11.7 |

### 2. Настройка окружения

#### 2.1 Пересоздание виртуального окружения

Скрипт удаляет существующую `.venv`, создаёт её заново, устанавливает
зависимости и Git hooks:

```bash
bash scripts/recreate_env.sh
```

#### 2.2 Установка зависимостей (если скрипт из пункта 2.1 не сработал)

Рекомендуется — через [uv](https://github.com/astral-sh/uv):

```bash
uv sync
```

Без uv:

```bash
pip install -r requirements.txt
```

> `requirements.txt` генерируется из `pyproject.toml` — не редактировать вручную.

### 3. Запуск

#### 3.1 C uv

```bash
uv run python src/main.py
```

#### 3.2 Без uv

```bash
source .venv/Scripts/activate
python src/main.py
```

### 4. Сборка EXE

Сборка с использованием уже подготовленного окружения:

```bash
bash scripts/build.sh
```

Полная последовательность с предварительным удалением и пересозданием `.venv`:

```bash
bash scripts/build_all.sh
```

> `build_all.sh` удаляет текущее виртуальное окружение через
> `recreate_env.sh`. Для обычной повторной сборки используйте `build.sh`.

## Ключевые кадры параметров сценария

В редакторе сценария откройте вкладку **Шкала параметров**. Это общая шкала
в секундах от начала сценария для всех каналов, как дорожки Dope Sheet.

1. Выберите канал и параметр, нажмите **+ Дорожка**.
2. Выберите время курсора и нажмите **+ Ключ**. Задайте значение и переход
   к следующему ключу: **Линейно** или **Скачком (удерживать)**.
3. Добавьте следующие ключи. Ромбы можно перетаскивать по времени;
   двойной щелчок открывает редактирование. Выделенные ключи можно удалять.
4. Задайте длительность шкалы и запустите сценарий общей кнопкой запуска.
   Последний ключ и граф шагов могут увеличить итоговую длительность.

Например, для постоянного сигнала добавьте дорожку **Тип сигнала** с ключом
«Постоянный» в `0 с`, затем дорожку **Постоянное значение** с ключами
`0 с → 20` и `10 с → 80`. Линейный переход увеличит значение от 20 до 80
за десять секунд. Каналы с ключами включаются при старте; дорожка **Включён**
позволяет выключать и включать их по времени.

Доступны постоянное значение, амплитуда, частота, смещение, границы диапазона,
скважность, длительность импульса, включение, тип сигнала и привязка вывода.
Тип сигнала, включение, устройство, модуль и адрес изменяются только скачком.
При смене устройства при необходимости задайте допустимый адрес ключом
в то же время. Выбранное подключение приложения остаётся прежним: дорожка
меняет привязку канала, а не открывает новое соединение.

До первого ключа параметр остаётся исходным, после последнего удерживается.
Дорожки перекрывают параметры шагов графа; их время не зависит от начала шага.
Можно создать сценарий только из дорожек. Пауза сохраняет время, повтор
начинает шкалу заново, остановка восстанавливает ручные настройки.
Старые сценарии без дорожек выполняются прежним способом.

Курсор показывает предпросмотр значений без вывода на оборудование.
Во время выполнения и паузы редактирование дорожек заблокировано.
Перед запуском проверяются ключи, адреса, диапазоны и конфликты выходов.

## Подключение МУ210-501

Приложение передаёт первые восемь аналоговых каналов напрямую в оперативные
регистры `3000–3007` модуля одной командой Modbus TCP. Значения масштабируются
в диапазон `0–1000`, соответствующий `0,0–100,0 %` диапазона выхода.

Для цепочки из нескольких МУ210 укажите их IP-адреса через запятую или точку с
запятой. Каналы распределяются последовательно: `A01–A08` на первый модуль,
`A09–A16` на второй, `A17–A20` на третий. В настройках аналогового канала
ручного режима номер модуля и выход `AO1–AO8` можно изменить. Свободные выходы
заполняются нулями, а дублирование одного выхода активными каналами блокирует
цикл записи и выводит ошибку в журнал. Подключение считается установленным
только после ответа всех модулей.

Аналоговые шаги сценария также могут выбирать модуль и выход МУ210. Эта
привязка действует только во время выполнения шага; после завершения или
остановки сценария восстанавливается привязка ручного режима.

Перед подключением реального оборудования задайте в ОВЕН Конфигураторе режим
каждого выхода (напряжение или ток) и безопасное состояние. Приложение не
изменяет эти параметры автоматически. Заводской IP модуля — `192.168.1.99`,
порт Modbus TCP — `502`; фактический адрес может отличаться после настройки.

В панели подключения сначала выберите тип устройства. Для `PLC Modicon
Premium` и `Simulator` используется исходная карта PLC (`0–59`), а для `ОВЕН
МУ210-501` — карта самого модуля. Окно «Регистры устройства» автоматически
показывает адреса и значения выбранного успешно подключённого устройства.
