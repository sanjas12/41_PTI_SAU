Запустите приложение

Наблюдайте за значениями 20 каналов

Кликните по имени любого канала - он будет выбран для графика

Нажмите "📊 Графики" - откроется окно с графиками

Управляйте генерацией кнопкой "Старт/Стоп"

Сбрасывайте сигналы кнопкой "Сброс"


1. ChannelWidget - Виджет одного канала:
Отображение имени канала (кликабельно)

Текущее значение

Полоска-индикатор

Тип сигнала

Включение/выключение канала

2. MainWindow - Главное окно:
Панель управления: Старт/Стоп, Сброс, Открыть графики

Статус: Индикация работы

Сетка каналов: 20 каналов в 5 колонок с прокруткой

Информационная панель: Modbus, выбранный канал, версия

3. Основные функции:
Генерация 20 аналоговых сигналов

Обновление в реальном времени (100 Гц)

Открытие отдельного окна с графиками

Выбор канала для графика кликом по имени

Включение/выключение отдельных каналов

Сброс всех сигналов

Отображение FPS
