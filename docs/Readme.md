# TG-Naladka

## Требования
- [Visual C++ Redistributable 2015–2022](https://aka.ms/vs/17/release/vc_redist.x64.exe)
- ОС: Windows 7 и выше

## Запуск
Дважды щёлкните `TG-Naladka.exe`.

## Проблемы
- Если программа не запускается — установите Visual C++ по ссылке выше.


🚀 Горячие клавиши:
    Комбинация	Действие
    Ctrl+O	Открыть сценарий
    Ctrl+S	Сохранить сценарий
    Ctrl+Shift+S	Сохранить настройки каналов
    Ctrl+Q	Выход
    Ctrl+K	Подключиться
    Ctrl+D	Отключиться
    Ctrl+1/2/3	Выбор устройства
    Ctrl+I	Интервалы обновления
    Ctrl+G	Графики
    Ctrl+R	Регистры устройства
    F1	О программе
