# План развития PTI_SAU

## Критично

### Оборудование и Modbus

- [ ] Проверять карту выходов перед запуском: находить дублирующиеся назначения
  `МУ210/AO`, отсутствующие модули и недопустимые регистры.
- [ ] Добавить безопасное состояние при потере связи и проверить его на
  испытательном стенде для PLC и МУ210.
- [ ] Читать аппаратные состояния МУ210 из регистров `3128–3135` и выводить в
  журнал обрыв нагрузки, короткое замыкание, перегрев ЦАП и другие ошибки.
- [ ] Проверить на реальном оборудовании масштабирование `0–1000`, порядок
  каналов, период записи и реакцию выходов на «Стоп».
- [ ] Исключить накопление фоновых Modbus-запросов при медленной связи.

### Конфигурация

- [ ] Привести корневой `settings.json` к валидному JSON.
- [ ] Применять runtime-настройки до вычисления зависящих от них констант.
- [ ] Проверять конфигурации каналов, подключений и сценариев до применения.

## Высокий приоритет

### Сценарии

- [ ] Проверять граф перед запуском: циклы, потерянные связи, отсутствующие
  каналы и конфликты физических выходов.
- [ ] Реализовать `ramp_up` и `ramp_down` либо временно убрать их из UI.
- [ ] Определить поведение параллельных шагов с одним каналом или выходом.
- [ ] Добавить `Undo/Redo` для блоков и связей.
- [ ] Предупреждать о несохранённых изменениях перед закрытием и загрузкой.
- [ ] Показывать результат шага: завершён, пропущен или завершён с ошибкой.

### Цепочка МУ210

- [ ] Добавить панель состояния: IP, подключение, последнее обновление и ошибка
  каждого модуля.
- [ ] Автоматически переподключать отдельный модуль без перезапуска приложения.
- [ ] Читать режимы из `3160–3167` и показывать диапазон каждого выхода.
- [ ] Добавить общий редактор `сигнал → модуль → AO → регистр`.

### Тестирование

- [ ] Добавить интеграционные тесты PLC, Simulator и цепочки МУ210 с fake
  Modbus-клиентом, включая частичную недоступность модулей.
- [ ] Проверить переходы `Старт → Пауза → Продолжить → Стоп` вместе с
  передаваемыми регистрами.
- [ ] Тестировать загрузку старых каналов и сценариев после изменения формата.
- [ ] Добавить тесты сохранения и восстановления пользовательских настроек.
